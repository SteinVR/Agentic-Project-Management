# Logs Directory

This folder stores logs from training runs, data processing, and other automated processes.

## Log Types

- `training_*.log` - Model training logs (epochs, loss, metrics)
- `preprocessing_*.log` - Data preprocessing and feature engineering logs
- `evaluation_*.log` - Model evaluation and validation logs

## Format

Logs should follow the format: `[YYYY-MM-DD HH:MM:SS] [LEVEL] - Message`
