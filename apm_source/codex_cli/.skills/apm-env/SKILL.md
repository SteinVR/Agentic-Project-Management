## What I do
- Translate the Architecture tech stack into concrete environment setup.
- Propose or create config files (pyproject, package.json, etc.).
- Provide setup commands and document the environment in STATE.

## Required reads
- `memory-bank/ARCHITECTURE.md`
- `memory-bank/STATE.md`

## Workflow
1. Read the Technology Stack and Deployment sections.
2. Propose the environment (runtime versions, package manager, core deps).
3. If approved, create or update config files.
4. Provide setup commands for the user.
5. Update `memory-bank/STATE.md` with environment notes.

## Required outputs
- Config file(s) if approved.
- `memory-bank/STATE.md` (updated)
