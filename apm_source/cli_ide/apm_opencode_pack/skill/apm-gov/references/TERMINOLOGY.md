# APM Terminology (Brief)

## RAPID
A lightweight product methodology for fast, structured delivery.
Focus: short feedback loops, minimal ceremony, disciplined Memory Bank updates.

## DS
A data science methodology built around experiments.
Focus: EDA → baseline → hypotheses → experiments → evaluation → model finalization.

## RAPID development workflow
The standard RAPID loop:
1. Read context (ARCHITECTURE/TASK/STATE).
2. Select a task and update `TASK.md`.
3. Plan briefly (Implementation Plan).
4. Implement in `src/`.
5. Verify with a quick run or tests.
6. Update `STATE.md` and mark tasks done.
7. Write a compact activity report (per apm-gov).
