# `apm-code-reviewer`

Use for independent verification and code review.

## Delegate when
- You need a maker-checker gate after implementation.
- You need independent task or architecture verification.

## Avoid
- Asking the reviewer to implement fixes.
- Pre-scoping the review to specific files -- the reviewer determines scope independently from the TASK_ID.
- Memory Bank updates.
- Git/worktree/PR operations.
