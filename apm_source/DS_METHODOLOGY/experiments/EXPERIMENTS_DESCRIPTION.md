# Experiments Directory

This folder contains experiment logs in Markdown format. Each experiment should be documented as a separate file.

## Naming Convention

`EXP-{number}_{short-description}.md`

Example: `EXP-001_baseline_random_forest.md`, `EXP-002_feature_engineering_v1.md`

## Experiment File Structure

Each experiment file should follow the EXPERIMENT_REPORT template from `.apm/AGENT_REPORTS/EXPERIMENT_REPORT.md`.
