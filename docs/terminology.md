# Термины APM

## RAPID
Методология для быстрых продуктовых итераций (MVP, прототипы, небольшие сервисы).
Фокус на коротком цикле разработки, минимальной церемонии и дисциплине Memory Bank.

## DS
Методология для проектов Data Science и ML.
Фокус на экспериментальном цикле: EDA → baseline → гипотезы → эксперименты → оценка → финализация модели.

## RAPID development workflow
Стандартный цикл разработки для RAPID проектов:
1. Прочитать контекст (Memory Bank: ARCHITECTURE/TASK/STATE).
2. Выбрать задачу и зафиксировать её в `TASK.md`.
3. Составить короткий план реализации.
4. Реализовать изменения в `src/`.
5. Проверить (smoke-test/тесты).
6. Обновить `STATE.md` и отметить выполненные задачи.
7. Зафиксировать краткий activity report (см. apm-gov).
