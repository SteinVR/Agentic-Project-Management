# Agents and Subagents
Цель - уменьшить оверфит агентов, и избавиться от не нужных.

- Сократить количество субагентов. Должны остаться только те, которые должны быть независимыми.
    Кандидаты на выбывание:
        - apm-architect - сделать скилл (apm-start) самодостаточным, без потребности в архитекторе.
        - apm-data-scientist/apm-engineer заменяются на универсального apm-worker.
            apm-worker - универсальная рабочая единица, минимум инструкций, только основное:
                1. В самом начале использовать todo list для выполнения задачи
                2. В конце задачи использовать Self-Review Gate.
        - apm-team-lead - уж лучше запускать отдельные инстансы вручную или неинтерактивный режим, чем доверять одному болвану руководить другими болванами.
        - apm-memory-bank-sync.md - слишком раздутый, нужно сжать.
- Убрать обязательные требования к TASK_ID.
- Skill routing - убрать.
- Guardrails - сократить. Заменить физическими ограничениями через permission.
