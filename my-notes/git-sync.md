# Синхронизация main и dev.
Я хочу иметь две раздельные ветки проекта: чистый main для публичного доступа и релизов и dev.

- Обе ветки должны иметь свою, независимую историю, свои не общие файлы, которые не должны переноситься, удаляться, копироваться из ветки в ветку при синхронизации обновлений тела проекта: apm_project и apm_source
- Для этого я хочу использовать файл типа .gitbranchignore, в котором прописывается все то, что не должно мигрировать и должно принадлежать только своей ветке. 
- Создать .sh скрипт, который будет выполнять синхронизацию веток за исключением объектов и папок (вместе со всем содержимом), которые хранятся в .gitbranchignore

Реализованный скрипт: git-branch-sync.sh
